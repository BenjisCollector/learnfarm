# أوبن فارم (Open Farm) 🌱

[English](README.md) · **العربية**

**تعلّم الزراعة بالحديث مع مساعدك البرمجي، وشاهد المزرعة تتحرك أمامك أثناء الحديث.**

أوبن فارم مجموعة مهارات مجانية ومفتوحة المصدر، ومعها محاكاة ثلاثية الأبعاد حيّة. اسأل مساعدك (Claude Code أو Codex أو Cursor أو Gemini CLI): *"ماذا تحتاج دجاجة واحدة طوال حياتها؟"* فيظهر قنّ دجاج بجانب المحادثة: العلف يدخل، والبيض يخرج، والأيام تمضي أمام عينيك.

وعندما تكون جاهزًا، أخبره بمدينتك وميزانيتك والمساحة المتاحة لديك، فيعطيك ثلاث طرق واقعية لبدء مزرعتك الخاصة، بما فيها الزراعة العمودية. ولكل طريقة تكلفتها وإنتاجها المتوقع ومدة استرداد رأس المال والمخاطر.

> **الحالة: المرحلة 0 (الأساسات).** لا شيء يعمل بعد. يحتوي هذا المستودع على الخطة والقرارات وعقد بيانات المشهد (Scene JSON). تابعنا أو افتح Issue.

## كيف يعمل

```
أنت ⇄ مساعدك البرمجي ── يحمّل مهارات أوبن فارم
              │
              ▼
        خادم MCP الخاص بأوبن فارم ──► محرك المحاكاة (نماذج محاصيل ومناخ حقيقية)
              │
              └── scene.json ──► العارض ثلاثي الأبعاد (لوحة جانبية، أو تبويب متصفح، أو داخل Claude/ChatGPT)
```

## القاعدة الأولى: الذكاء الاصطناعي لا يخترع الأرقام

كل رقم (المحصول، الماء، التكلفة) يأتي من نموذج حسابي ثابت أو من بيانات منشورة، ويحمل مصدره (`source`). المساعد يشرح، والمحرك يحسب.

## ثنائي اللغة من اليوم الأول

كل اسم ووصف في المشهد له نسخة إنجليزية وعربية (`{"en": "...", "ar": "..."}`).

## خارطة الطريق

| المرحلة | ما سيُطلق |
|---|---|
| 0 | الاسم، التراخيص، عقد المشهد v0 ← **أنت هنا** |
| 1 | **نموذج الدجاجة الأول**: دجاجة واحدة، وعدّادات حيّة لما يدخل وما يخرج، داخل Claude Code |
| 2 | مسار تعليمي من 8 دروس (التربة، الماء، الضوء، المحاصيل، الحيوانات، الآفات، الزراعة العمودية، المال) |
| 2.5 | **تحدّي المزرعة**: لعبة قرارات. مواقف باختيار من متعدد، والمزرعة تُظهر نتيجة كل قرار |
| 3 | نماذج حقيقية: مناخ من Open-Meteo و NASA POWER، ومحاصيل من AquaCrop و WOFOST |
| 3.5 | **عارض ثلاثي الأبعاد بأسلوب البكسل**: Three.js بدقة منخفضة وتظليل كرتوني. نفس المشهد بمظهر احترافي |
| 4 | المخطِّط + وحدة الزراعة العمودية (التكلفة الرأسمالية، التشغيل، الاسترداد، المخاطر) |
| 5 | دعم كل المساعدات + واجهة داخل المحادثة (MCP Apps) ← الإصدار 1.0 |
| 6 | حزم إقليمية (الخليج أولًا) + المجتمع |

الخطة الكاملة والبحث في [docs/OPEN-FARM-PLAN.md](docs/OPEN-FARM-PLAN.md)، والقرارات في [DECISIONS.md](DECISIONS.md).

## شغّلها

```bash
python3 -m http.server 5173
```

افتح http://localhost:5173/viewer/ بجانب مساعدك. يقرأ العارض ملف `examples/farm.scene.json` كل ثانية. اطلب من مساعدك تعديل الملف ("أضف ١٠ ماعز إلى الحظيرة"، "اجعلها تمطر") فتتحدّث المزرعة أمامك مباشرة.
