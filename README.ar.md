# أوبن فارم (Open Farm) 🌱

[English](README.md) · **العربية**

<p align="center"><img src="docs/media/open-farm.gif" width="720" alt="أوبن فارم: مزرعة مجسّمة ثلاثية الأبعاد تنتقل فيها الحبات الملوّنة بين المناطق، والضغط على حظيرة الحيوانات يُظهر ما تحتاجه وما تعطيه، وإيقاف المضخة يُحمّر المزرعة مع جفاف الخزان"></p>

<p align="center"><a href="https://yusufmufeed.uk/open-farm?lang=ar"><b>الموقع والعرض الحي: yusufmufeed.uk/open-farm</b></a></p>

**تعلّم الزراعة بالحديث مع مساعدك البرمجي، وشاهد المزرعة تتحرك أمامك أثناء الحديث.**

أوبن فارم مجموعة مهارات مجانية ومفتوحة المصدر، ومعها محاكاة حيّة لمزرعة ثلاثية الأبعاد. اسأل مساعدك (Claude Code أو Codex أو Cursor أو Gemini CLI): *"ماذا تحتاج دجاجة واحدة طوال حياتها؟"* فيظهر قنّ دجاج بجانب المحادثة: العلف يدخل، والبيض يخرج، والأيام تمضي أمام عينيك.

وعندما تكون جاهزًا، أخبره بمدينتك وميزانيتك والمساحة المتاحة لديك، فيعطيك ثلاث طرق واقعية لبدء مزرعتك الخاصة، بما فيها الزراعة العمودية. ولكل طريقة تكلفتها وإنتاجها المتوقع ومدة استرداد رأس المال والمخاطر.

> **الحالة: المرحلة 1 (نموذج الدجاجة الأول).** العارض ثلاثي الأبعاد ومحرّك الحسابات ومهارة Claude Code تعمل اليوم. تابعنا أو افتح Issue.

## كيف يعمل

```
أنت ⇄ مساعدك البرمجي ── يحمّل مهارات أوبن فارم
              │
              ▼
        خادم MCP الخاص بأوبن فارم ──► محرك المحاكاة (نماذج محاصيل ومناخ حقيقية)
              │
              └── scene.json ──► العارض ثلاثي الأبعاد (لوحة جانبية، أو تبويب متصفح، أو داخل Claude/ChatGPT)
```

## القاعدة الأولى: الذكاء الاصطناعي لا يخترع الأرقام

كل رقم (المحصول، الماء، التكلفة) يأتي من نموذج حسابي ثابت أو من بيانات منشورة، ويحمل مصدره (`source`). المساعد يشرح، والمحرك يحسب.

## ثنائي اللغة من اليوم الأول

كل اسم ووصف في المشهد له نسخة إنجليزية وعربية (`{"en": "...", "ar": "..."}`).

## شغّلها

```bash
python3 -m http.server 5173
```

افتح http://localhost:5173/viewer/ بجانب Claude Code وهو مفتوح داخل هذا المستودع. يقرأ العارض ملف `examples/farm.scene.json` كل ثانية. قل "أضف ١٦ دجاجة واجعلها تمطر": مهارة `open-farm` ([skills/open-farm/SKILL.md](skills/open-farm/SKILL.md)) تعدّل المشهد وتشغّل المحرّك، فتتحدّث المزرعة أمامك خلال ثانية تقريباً.

## المحرّك

لا تُكتب أرقام المدخلات والمخرجات باليد. الملفان `data/animals.json` و `data/crops.json` يحملان المعدّلات لكل رأس ولكل متر مربع، وكل معدّل له مصدر في [docs/research](docs/research/README.md). المحرّك يضربها في `props.count` أو `props.area_m2`:

```bash
python3 -m engine.build examples/farm.scene.json
```
